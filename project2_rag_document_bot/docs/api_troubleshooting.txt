# DataFlow API Developer & Troubleshooting Guide

## 1. Authentication Errors (401 Unauthorized)
If your API calls return HTTP 401, verify that your Bearer Token is passed in the request header: `Authorization: Bearer <YOUR_API_TOKEN>`. Tokens expire after 24 hours.

## 2. Server Rate Limits (429 Too Many Requests)
Standard tier API keys are rate-limited to 100 requests per minute. When limit is exceeded, the server responds with HTTP 429 and a `Retry-After` header indicating delay in seconds.

## 3. Server Errors (500 Internal Server Error)
HTTP 500 errors indicate database sync latency or backend microservice failure. Check live service status at status.dataflow-example.io or notify devops@dataflow-example.io.
